Built for the hardware.

Every detail here exists because a Walkman E-series refused to display something.

Clean song titles

Strips Official Music Video, 4K, 2023 Remaster, genre tags and hashtags — while keeping real titles like Breathe (In the Air) intact.

Album art that renders

500×500 square, re-encoded as baseline JPEG. Progressive JPEGs show up blank on Walkman firmware.

ID3v2.3, not v2.4

With an ID3v1 tail. Latin-1 text, UTF-16 where needed — UTF-8 frames render as garbage on these players.

Real track numbers

Album links resolve the whole release in one lookup, so every song shares one album name, year, cover and correct order.

Fits your size cap

320 kbps costs 2.4 MB a minute. Pick a per-file cap and each track gets the highest legal bitrate that fits under it.

Foldered for the device

Artist/Album/01 - Title.mp3, FAT32-safe names, shallow paths. Drag the folders straight into MUSIC.

Paste anything.

Audio is fetched only from sites that serve it openly.

YouTube YouTube Music SoundCloud Bandcamp Mixcloud Audiomack
Spotify and Apple Music links work differently. Their audio is DRM-protected and this tool never touches it. Only the public tracklist is read — song names, artists, durations — and each song is then located on one of the open sites above. You get the right tags; their streams stay untouched.

Install.

Runs on your own machine. Needs Python 3.10+ and ffmpeg.

git clone https://github.com/reddotconsultancy/walkman-music-downloader.git
cd walkman-music-downloader
./setup.sh
./run.sh

Opens at localhost:7788. There is a CLI too.
